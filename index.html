☁️ Synchronizacja między urządzeniami

Połącz tracker z GitHub Gist — dane będą dostępne na telefonie, komputerze i wszędzie. Potrzebujesz konta GitHub (masz je już jako piotrpavv-blip).

  1. Wejdź na github.com/settings/tokens/new
  2. W polu Note wpisz: Dziennik Redukcji
  3. W sekcji Select scopes zaznacz tylko: ✅ gist
  4. Kliknij zielony przycisk Generate token na dole
  5. Skopiuj token (zaczyna się od ghp_) i wklej poniżej
Token jest zapisywany tylko lokalnie na tym urządzeniu. GitHub może go wyświetlić tylko raz!
✅ Synchronizacja aktywna

💡 Dane synchronizują się automatycznie po każdym zapisie wpisu oraz przy otwarciu strony. Kliknij ikonę ☁️ w nagłówku aby zsynchronizować ręcznie.
